# Dear Spokes

An interactive photo essay documenting a 75-day, 4,037-mile cycling journey across America with STEM education workshops for underserved communities.

## View Live

**[sophiajwang.github.io/spokes-photo-essay](https://sophiajwang.github.io/spokes-photo-essay/)**

## Navigation

- **Scroll** or **swipe** to move through sections
- **Arrow keys** or **spacebar** also work
- Some sections have multiple images—keep scrolling to see them all

## Tech

Vanilla HTML/CSS/JS. No frameworks, no build step. Just open `index.html`.
